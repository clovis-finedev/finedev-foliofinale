# 📁 Portfolio Développeur Full Stack

**Un portfolio moderne avec Flask, déployé sur Vercel**  
[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fvotre-utilisateur%2Fvotre-repo)

## ✨ Fonctionnalités
- 🖥️ **Page d'accueil responsive** avec animation JavaScript
- 📩 **Formulaire de contact** avec envoi d'emails SMTP
- 🔄 **Convertisseur intégré** (FineConvert)
- 🖼️ **Galerie de projets** avec aperçu visuel
- 📱 **Design adaptatif** pour mobile/desktop

## 🛠 Stack Technique
| Composant       | Technologies                          |
|-----------------|---------------------------------------|
| Frontend        | HTML5, CSS3, JavaScript               |
| Backend         | Python/Flask                          |
| Email           | SMTP via Gmail                        |
| Déploiement     | Vercel                                |
| Assets          | Stockés dans `public/images/`         |
